The verification environment

This book's examples are not illustrative — they are captured. Every Rust block on every page was compiled with rustc 1.98.1: the programs that ran, and the compiler refusals quoted verbatim, came from that exact compiler. The C comparisons were compiled with clang 14.0.0 and gcc 11.4.0, with AddressSanitizer and ThreadSanitizer builds where the point was memory corruption or a race. The machinery lives in the repository: tools/verify.py extracts each code block from the pages, rebuilds it, and records the outcome in tools/verify-report.json; tools/check.py enforces the page contracts — terms defined before use, provenance marks near numeric claims, word windows, offline purity. Nothing ships red.
