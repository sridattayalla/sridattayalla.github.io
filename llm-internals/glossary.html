Glossary

Every term this book defined, one line each. Entries are grouped by the part where the term first appears, and the linked title at the end of each line points to the page that defines it.

Start

Token
The unit of text a model reads and writes — usually a frequent character sequence, not a word. How LLMs Actually Work
Model
The trained network itself: an architecture plus learned weights. How LLMs Actually Work
Language model
A model trained to assign probabilities to text, one next piece at a time. How LLMs Actually Work

Part One — The Machine

Parameter
One learned number in the network; together they hold the model's knowledge. The Core Idea
Weights
The learned numbers collectively — what training changes. The Core Idea
Forward pass
One run of input through the layers to an output. The Core Idea
Logits
Raw scores, one per vocabulary entry, before normalization. The Core Idea
Softmax
Turns scores into probabilities that sum to one. The Core Idea
Probability distribution
A probability for every possible next piece. The Core Idea
Autoregressive
Generating one piece at a time, each conditioned on all earlier pieces. The Core Idea
Inference
Running a trained model, as opposed to training it. The Core Idea
Transformer
The architecture of this book: stacked attention and feed-forward layers. The Core Idea
Layer
One repeatable stage of the stack, feeding the next. The Core Idea
Vocabulary
The fixed list of pieces the model can read or emit. Tokens
BPE
Byte-pair encoding: pieces built by merging frequent pairs. Tokens
Byte-level BPE
BPE over raw bytes, so any text is coverable. Tokens
Merge
One learned combination of two pieces into one longer piece. Tokens
Token ID
The vocabulary index of a piece — the integer the model consumes. Tokens
Special token
A reserved piece marking structure: roles, boundaries, ends. Tokens
Detokenization
Turning pieces back into text; split characters wait for their bytes. Tokens
Vector
An ordered list of numbers — the model's container for meaning. Embeddings
Embedding
The vector a piece becomes at the input. Embeddings
Embedding matrix
The lookup table with one row per vocabulary entry. Embeddings
One-hot
All zeros with a single one — a raw row selector. Embeddings
Dot product
Multiply matching entries and sum — the similarity workhorse. Embeddings
Matrix multiply
Every output row as dot products, batched. Embeddings
Dimension
The length of a vector; the width of a layer. Embeddings
Hidden state
A layer's internal vector for one position. Embeddings
Tensor
A multi-dimensional array; stacked vectors. Embeddings
Permutation invariance
Attention alone cannot tell order; position must be added. Position
Positional encoding
Any scheme that injects order into the vectors. Position
Sinusoidal encoding
The original order signal: fixed sines at many frequencies. Position
RoPE
Rotate queries and keys by position-dependent angles, so dot products carry relative distance. Position
Query
The vector asking: what am I looking for? Attention
Key
The vector advertising: what do I contain? Attention
Value
The vector delivered when a position is selected. Attention
Attention weights
Normalized scores deciding how much of each position is gathered. Attention
Causal mask
Scores to future positions zeroed — look behind only. Attention
Attention
Each position takes a weighted average of earlier values. Attention
Context window
Everything one forward pass can see. Attention
Head
One attention computation in its own subspace. Attention
Multi-head attention
Many heads per layer, each with its own queries, keys, values. Multi-Head and GQA
GQA
Grouped-query attention: query heads share key-value heads — a smaller cache. Multi-Head and GQA
MQA
Multi-query attention: one shared key-value head — the smallest cache. Multi-Head and GQA
KV cache
Stored keys and values of earlier positions, so decode skips recompute. Multi-Head and GQA
FFN
The feed-forward network: a per-vector two-layer transform. The Feed-Forward Network
Activation function
The nonlinearity between the two linear maps. The Feed-Forward Network
SwiGLU
The modern gated activation: one map decides, one supplies. The Feed-Forward Network
Expansion ratio
How much wider the feed-forward hidden layer is. The Feed-Forward Network
Residual connection
Adding a sublayer's output back to its input. The Transformer Block
Residual stream
The running sum every sublayer reads and writes. The Transformer Block
LayerNorm
Normalize each vector before a sublayer reads it. The Transformer Block
RMSNorm
The cheaper norm: root-mean-square scaling only. The Transformer Block
Pre-norm
Normalize before the sublayer, keeping the residual path clean. The Transformer Block
Transformer block
One full repeat: attention, then feed-forward, on the stream. The Transformer Block

Part Two — Training

Loss
The number training minimizes — the penalty for wrong predictions. The Training Objective
Cross-entropy
Minus the log probability given to the correct next piece. The Training Objective
Log probability
Log of a probability; products become sums. The Training Objective
Perplexity
Exponentiated loss — the effective number of choices. The Training Objective
Corpus
The training text: trillions of pieces. The Training Objective
Pretraining
The largest stage: next-piece prediction over the corpus. The Training Objective
Batch
Examples processed together for one update. The Training Objective
Gradient
The derivative of loss per parameter — the direction to move. Backpropagation
Backpropagation
All gradients in one backward sweep. Backpropagation
Chain rule
Derivatives through composition multiply. Backpropagation
Computational graph
The recorded operations of the forward pass, reused backward. Backpropagation
Autograd
Library machinery that differentiates the record automatically. Backpropagation
Learning rate
The step size — how far each update moves. Backpropagation
Gradient descent
Nudge parameters against their gradients, repeatedly. Backpropagation
AdamW
The standard optimizer: adaptive steps plus decoupled weight decay. Backpropagation
Activations
Intermediate values saved for the backward sweep. Backpropagation
FLOPs
Floating-point operations — the count of arithmetic. GPUs
HBM
High-bandwidth memory: the card's large pool. GPUs
SRAM
On-chip memory: tiny, fast, precious. GPUs
Tensor core
The matrix-multiply unit — where arithmetic happens. GPUs
Memory bandwidth
Bytes per second the card can move. GPUs
Compute-bound
Limited by arithmetic capacity. GPUs
Memory-bound
Limited by data movement. GPUs
Mixed precision
Compute low, store master weights high. GPUs
Tensor parallel
Split one layer's matrices across cards. GPUs
Pipeline parallel
Split the layer stack into stages. GPUs
Data parallel
Copy the model, split the data, average gradients. GPUs
Gradient checkpointing
Discard activations, recompute backward — memory for time. GPUs
Scaling laws
Curves predicting loss from size, data, and compute. Scaling Laws
Chinchilla-optimal
The compute-matched balance of parameters and tokens. Scaling Laws
Parametric knowledge
Knowledge stored in weights, not files. Scaling Laws

Part Three — The Assistant

Base model
The raw pretrained model — an autocompleter without manners. Post-Training
Instruction tuning
Teaching instruction-following from demonstrations. Post-Training
SFT
Supervised fine-tuning on example dialogues. Post-Training
RLHF
Reinforcement learning from human feedback. Post-Training
Reward model
A trained judge of human preference. Post-Training
DPO
Preference training without a separate reward model. Post-Training
Chat template
Serialization of a messages array into one token string. Post-Training
System prompt
Persistent instructions framing the conversation. Post-Training
Hallucination
Confident output ungrounded in the weights. Post-Training
Catastrophic forgetting
Old skills overwritten by narrow fine-tuning. Post-Training
Prompt
Everything sent in one request: framing, history, new turn. Post-Training
Sampling
Drawing the next piece instead of taking the top one. Sampling
Greedy decoding
Always take the highest-probability piece — repetitive, loop-prone. Sampling
Temperature
Divide logits before softmax: lower sharpens, higher flattens. Sampling
Top-k
Keep only the k best candidates. Sampling
Top-p
Keep the smallest set whose probabilities reach p. Sampling
Nucleus sampling
Top-p — the kept set is the nucleus. Sampling
Beam search
Track several partial sequences, keep the best. Sampling

Part Four — Inference at Scale

Decode
The serial phase: one piece per pass. The Inference Loop
TTFT
Time to first token: queueing plus prefill. The Inference Loop
TPOT
Time per output token: the per-piece decode cost. The Inference Loop
Prefill
The parallel first pass over the prompt. The Inference Loop
Decode phase
The memory-bound loop after prefill. The Inference Loop
EOS
The end-of-sequence piece — the vote to stop. The Inference Loop
Latency
Response time as the user perceives it. The Inference Loop
Batching
Serving many requests per weight read. Serving
Continuous batching
Admit and retire requests every step. Serving
Iteration-level scheduling
Re-plan the batch at each decode step. Serving
Selective batching
Prefill unbatched, decode batched. Serving
PagedAttention
The cache in fixed-size blocks with a block table. Serving
Block table
The per-request map of cache blocks to positions. Serving
Throughput
Pieces per second across all requests. Serving
FlashAttention
Exact attention tiled inside on-chip memory. Serving
Tiling
Big matrix multiplies as cache-sized tiles. Serving
Quantization
Weights as small integers times a scale factor. Quantization
Scale factor
The multiplier mapping integers back to real values. Quantization
Outlier
A channel with far larger values — the spoiler. Quantization
GPTQ
Post-training quantization, compensated column by column. Quantization
AWQ
Activation-aware: protect the salient channels. Quantization
Weight-only quantization
Quantize weights; dequantize on the fly to compute. Quantization
Speculative decoding
A small model proposes; the big model verifies in one pass. Speculative Decoding
Draft model
The small, cheap proposer. Speculative Decoding
Target model
The real model the output must match. Speculative Decoding
Acceptance rate
How often proposals survive the check. Speculative Decoding
EAGLE
Feature-level drafting: predict hidden states, not pieces. Speculative Decoding

MoE

Expert

MLA

Test-time compute

Chain of thought

RLVR

Thinking budget
The dial for per-query inference compute. The Whole Machine
