Sources and Further Reading

Every number in this book carries a bracketed tag. The tag names a research sheet — a file in this repository where the number was pinned to a primary source. This page lists those sheets in reading order, with the sources beneath each. The runnable model behind the code excerpts is code/tiny_llm.py, and every sheet lives under research/ in this repository.

The toy attention example

Behind the attention page's worked numbers: the tiny query-key-value arithmetic and the pronoun-binding example, recomputed locally.

  • Attention Is All You Need (2017) — the attention formula, the score-scaling rationale, the example that inspired the toy.
  • research/attention-example.md — the sheet, with the recomputed numbers.

Tokenization

Behind the tokens page: how byte-pair encoding builds a vocabulary, why GPT-2 moved to bytes, and how detokenization buffers split characters.

  • Neural Machine Translation of Rare Words with Subword Units (2016) — byte-pair encoding for text.
  • Language Models are Unsupervised Multitask Learners (2019) — GPT-2's byte-level vocabulary.
  • tiktoken — the tokenizer behind the API, with incremental detokenization.
  • The Llama 3 Herd of Models (2024) — a modern vocabulary, sized.
  • research/tokenization.md — the sheet, with local tokenizer runs.

Components: RoPE, GQA, SwiGLU, the norms

Behind the machine pages: the position rotations, the shared key-value heads, the gated activations, and the two released configurations that ground the dimensions.

  • RoFormer: Enhanced Transformer with Rotary Position Embedding (2021) — rotations as position.
  • GQA: Training Generalized Multi-Query Transformer Models (2023) — shared key-value heads.
  • GLU Variants Improve Transformer (2020) — SwiGLU.
  • Root Mean Square Layer Normalization (2019) — RMSNorm.
  • Layer Normalization (2016) — the original norm.
  • Meta-Llama-3-8B config.json and Llama-2-7B config.json — released configurations.
  • research/components.md — the sheet, with local numpy runs.

The training objective and its laws

Behind Part Two's objective pages: cross-entropy over a corpus, the scaling curves that predict loss, and the optimizer that walks it down.

  • GPT-3 (2020) — training at scale.
  • Scaling Laws for Neural Language Models (2020) — the Kaplan curves.
  • Training Compute-Optimal Large Language Models (2022) — Chinchilla.
  • Decoupled Weight Decay Regularization (2017) — AdamW.
  • The Llama 3 Herd of Models (2024) — a modern training run's bill.

How to check any of this

Find a number's bracketed tag, open the named sheet in this repository, and follow its source. For the code excerpts, run code/tiny_llm.py — it is deterministic, prints every stage's output, and finishes in seconds.
