Typography

Heading three in the body face

Body prose at seventeen pixels with a sixty-five percent line height ratio. Strong text uses weight 590. Emphasis leans italic. Small print drops to fourteen pixels. Inline code reads like attn(x) and keyboard hints like Esc. Prose links keep the accent color and an offset underline, as in this link back to Typography.

Takeaways

  • Square bullets carry the accent, and the panel uses the green wash.
